# Veldra

A modern, responsive administrative dashboard interface built with vanilla JavaScript, HTML, and CSS. This project features a clean, warm-toned aesthetic with pastel analytics cards, an off-canvas navigation drawer, interactive data tables, and scalable icon support.

## Features

* **Warm Minimalist Aesthetic:** Designed with a curated warm light theme palette, soft pastel accents, rounded modern geometry, and subtle shadows.
* **Off-Canvas Responsive Navigation:** Smooth slide-out mobile drawer with backdrop blur, keyboard accessibility (`Esc` dismiss), automatic viewport resize resets, and active pill state transitions.
* **Analytics & Metric Cards:** Highlights key business metrics (Revenue, Active Users, Orders, Conversion Rate) with trend indicators and pastel background highlights.
* **Interactive Data Table:** Responsive recent activity table complete with user avatars, status badges (`Completed`, `In Progress`, `Pending`, `Cancelled`), and contextual action triggers.
* **Modern Header & Controls:** Sticky header featuring a search bar, notification indicators, user profile card, and primary/secondary action buttons.
* **Cross-Device Responsive Design:** Flexible layouts powered by CSS Grid and Flexbox with dedicated breakpoints for desktops, tablets, and mobile devices (including iOS font scaling prevention).

## Technologies Used

* **HTML5:** Semantic document structure (`<aside>`, `<header>`, `<main>`, `<section>`, `<table>`, `<canvas>`), meta viewport, and descriptive ARIA labels.
* **CSS3:** CSS Grid, Flexbox, custom CSS custom properties (variables), responsive media queries, backdrop filters, custom scrollbars, and keyframe animations.
* **JavaScript (ES6+):** DOM manipulation, off-canvas drawer toggle logic, backdrop events, active navigation management, and keyboard accessibility listeners.
* **Lucide Icons:** Clean, modern SVG icon set loaded via CDN for consistent UI visual hierarchy.
* **Google Fonts:** Clean modern typography powered by Inter (`wght@300;400;500;600;700`).

## How to Run Locally

Since this is a vanilla front-end project, no build tools or package managers are required.

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/arinskyyyy/admin-dashboard.git
   ```

2. Navigate into the project directory:
   ```bash
   cd admin-dashboard
   ```

3. Open the `index.html` file in your preferred web browser.
